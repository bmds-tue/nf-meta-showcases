# Metapipeline Showcases with nf-meta

This repository contains showcases of metapipelines build and run with [nf-meta](https://pypi.org/project/nf-meta/)

# Requirements

1. Nextflow installation is required to run the individual pipelines
2. `nf-meta` installation required:
    ```python
    # with pip 
    pip install nf-meta

    # with uv
    uv add nf-meta
    ```
